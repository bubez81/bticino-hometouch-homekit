# Development update — 2026-10-04

This update publishes the experimental dedicated Homebridge plugin and the
listener modules developed during September. It is not a stable release or
an automatic migration from Camera-ffmpeg.

## Included

- Dedicated camera/doorbell plugin with local IPC, encrypted video transport,
  receiver diagnostics and bounded source renewal.
- Incoming-call ownership, explicit answer/hangup and gated two-way audio.
- Optional contextual opening and a separate `BTicinoCallLock` accessory.
  Its closed/open/closed display is assumed state, not sensor feedback.
- Redacted entrance-signaling diagnostics and private camera discovery.
- Existing SIP endpoint recovery and a macOS credential migration helper
  that preserves previous credentials in a private backup.

## Validation and limits

On October 4 a dedicated account was provisioned and installed on the test
system. The gateway accepted SIP registration. A HomeKit video session received
packets and returned receiver reports; this alone does not prove source freshness.
That on-demand session used diagnostic silence, not the outdoor microphone.
Notification, full conversation and physical opening after account migration
still need a real doorbell call. HKSV recording is not implemented.

Opening an incoming live session can accept the call and affect other clients.
Contextual opening remains opt-in and requires an established owned incoming
call. Command submission is not confirmation that the door physically opened.
See [contextual opening](contextual-unlock.md) for the guards and limitations.

## Accounts and full device lists

The tested installation allows 20 SIP endpoints. The HOMETOUCH wall panel's
**Settings → Account → user → Disconnect beside an obsolete smartphone** can
remove an individual device. Avoid disconnecting the entire user unnecessarily.
Removing the user's last device can also disassociate that user. This procedure
was verified on the test installation; menu labels depend on firmware/language.

If creation reports HTTP 201 with an empty response, do not create again.
Run `--list-endpoints`, then use `--reuse-endpoint 'exact unique name' --apply`
with a new/empty output directory to recover the endpoint and obtain a certificate.
Credentials and certificates must remain outside this repository.

## Deployment

The normal installer continues configuring the Python listener; the dedicated
plugin is supplied as source under `homebridge-bticino-hometouch/`. See its
example configuration and schema. It is not published to npm by this update.
The `deploy-*.py` scripts are historical, installation-specific maintenance
tools with fixed paths, not a supported general-purpose installer. Review them
before use. `migrate-dedicated-account.py` likewise targets the documented macOS
paths and requires already-provisioned files; it does not remove cloud endpoints.

Earlier dated research/validation notes describe intermediate states. This
update and the current source supersede their statements about missing modules
or temporary foreground deployment.
